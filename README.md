# Splunk Log Analysis SIEM Project

## Overview

This project demonstrates the implementation of Splunk SIEM for security log collection, ingestion, analysis, and threat detection. The project focuses on detecting failed login attempts, identifying suspicious IP addresses, and investigating Windows security events using SPL (Search Processing Language).

The objective was to simulate real-world SOC analyst activities by collecting logs, indexing data, performing searches, and identifying potential security threats.

## Objectives

* Install and configure Splunk Enterprise
* Collect and ingest system security logs
* Create custom indexes
* Analyze Windows Event Logs
* Detect failed login attempts
* Identify suspicious IP addresses
* Perform security investigations using SPL queries

## Tools Used

* Splunk Enterprise
* NirSoft LastActivityView
* NirSoft FullEventLogView
* Windows Event Logs
* SPL (Search Processing Language)

### Suspicious IP Detection

* Performed behavioral analysis
